# AI Spam Detector — Dataset

This directory contains the datasets used to train and evaluate
the AI Spam Detector machine learning model.

## Dataset

We will use a publicly available dataset containing spam
and legitimate text messages.

## Data Processing

The dataset will be processed using Python and pandas.

Text messages will be converted into numerical features
using TF-IDF vectorization.

## Note

Large or locally downloaded datasets are excluded from
Git tracking.

Dataset source, licensing, and download instructions
will be documented when the dataset is selected.
